# Test whether a version satisfies a single constraint

Test whether a version satisfies a single constraint

## Usage

``` r
version_satisfies(version, constraint)
```

## Arguments

- version:

  A version string (CRAN style, may contain `-`).

- constraint:

  One of `"x.y.z"`, `"==x"`, `">=x"`, `"<=x"`, `">x"`, `"<x"`.
