# Query a specific table in the Postgres database containing the metadata

Query a specific table in the Postgres database containing the metadata

## Usage

``` r
query_metadata_table(table = "single_builds")
```

## Arguments

- table:

  (character)  
  Table name. See
  [`list_metadata_tables()`](https://bincraft.doc.rpkgs.com/reference/list_metadata_tables.md)
  for valid tables.
